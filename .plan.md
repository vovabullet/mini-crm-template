# Mini-CRM Development Plan

## Project Overview
Mobile-first CRM template for service workers (confectioners, auto mechanics, etc.) to manage incoming orders with quick access to order details, photos, and specifications during work.

## Design Requirements
- Mobile-first (phone-optimized)
- Fast and convenient for one-handed use
- Modern design with rounded corners
- Smooth animations and transitions
- Easy access to order details while hands are busy
- Photo support for orders

## Technical Stack (Proposed)
- **Frontend**: HTML5, CSS3, Vanilla JavaScript (lightweight, no dependencies)
- **Storage**: LocalStorage for demo/template (easily replaceable with API)
- **Design**: Custom CSS with CSS Grid/Flexbox
- **Icons**: SVG icons (embedded for speed)
